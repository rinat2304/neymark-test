# Задание 1 — Палиндром

## Требование

Реализовать на PHP функцию, которая определяет, является ли переданный текст палиндромом.

## Принятые правила

Перед проверкой текст нормализуется:

1. регистр не учитывается;
2. пробелы игнорируются;
3. знаки препинания и прочие неалфавитно-цифровые символы игнорируются;
4. поддерживается UTF-8;
5. пустая строка после нормализации считается палиндромом.

## Примеры

```text
racecar                          true
RaceCar                          true
A man, a plan, a canal: Panama   true
А роза упала на лапу Азора       true
hello                            false
12321                            true
```

## Тест-кейсы

Набор тестов находится в `tests/PalindromeTest.php`.

Проверяются:

* обычные палиндромы;
* строки в разных регистрах;
* строки с пробелами и знаками препинания;
* палиндромы на русском языке;
* строки из цифр;
* пустая строка;
* строка из одного символа;
* строки, состоящие только из пробелов или знаков;
* непалиндромные строки.

Всего предусмотрено 16 тест-кейсов.

## Запуск тестов

Установить зависимости:

```bash
composer install
```

Запустить PHPUnit:

```bash
vendor/bin/phpunit
```

## Ограничения

Функция не должна изменять входные данные и должна возвращать только `true` или `false`.

## Сложность

Целевая сложность — O(n) по времени.

Дополнительная память может составлять O(n), если для корректной обработки UTF-8 используется массив символов.
